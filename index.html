Source model & governance

Three of the five features pull from external evidence. None touch the open web or the AI's internal knowledge for clinical claims. They draw from one governed catalog, through a personal scope the doctor controls, behind a review gate. Defined once here so the feature flows can reference it.

01

Two layers, never confused

The confusion clears the moment trust (a property of the source, owned centrally) is separated from scope (a choice the doctor makes per session).

Layer 1 — global
The Trust Catalog

Every AI-usable source sits in one master catalog, tagged Tier (1–3, how far we trust it) × Type (A/B/C, what kind of content it is). A doctor cannot re-rate it.

owned by Admin / Medical Board
Layer 2 — per doctor, per session
Working Scope

When exploring, the doctor picks which tiers and types to draw from for that session. "Pull Tier 2 up into my search" includes it in their session — it does not change the catalog for anyone else.

03

Elite uploads — the promotion pipeline

A strong PDF from a credentialed doctor should enrich the library, so a junior doctor can later read it as a high-trust resource. The safe path is promotion, not auto-caching. Credential routes and weights; the human reviewer is the gate.

01
Upload

PDF is private to that doctor by default — used only as their own working context. Nothing shared.

02
Contribute

Doctor opts to "Contribute to library." It enters a candidate queue.

03
Credential weighting

System reads the verified profile — institution, qualification, medical-registration number — and attaches a credibility signal that sets a suggested tier and fast-tracks review.

04
Human review

Reviewer checks licence/copyright, patient data, accuracy, relevance — then assigns the final tier & type.

05
Shared

Now discoverable to others within their allowed tiers, badged with the contributor's institution / association.

RISK

Copyright is the single biggest risk here. Caching one doctor's paywalled NEJM/Lancet PDF and serving it to others is redistribution. Default-private uploads plus a licence check before any sharing is non-negotiable. Patient data (PHI) gets a scrub/consent step on the same gate. And credential is a routing signal, not a correctness stamp — an elite badge never auto-blesses a file as Tier 1.
